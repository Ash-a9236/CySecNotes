<br>

### <a name="base-concepts"><span style="color: var(--title)">00.00 INTRODUCTION</span></a>

<hr>

<br>
Active reconnaissance is a set of techniques where attackers gather information on their target <span style="color: var(--highlight)">having direct contact</span>, which will gather better and more information but also more risky. Active recon will be logged by the target which presents more risks for the attacker.

For example, the target could have IDS/IPS alerts (such as ```snort``` or ```zeek```) which could generate alerts such as :
```
Possible port scan detected
Source: 203.0.113.15
```


To install all the commands on a linux system (debian-based) : 

```bash
sudo apt install netdiscover -y
```

### <a id="traceroute"><span style="color: var(--title)">01.00 TRACEROUTE</a>

<hr><br>

*extra*

It is important to note that certain routers will ignore the traceroute probe or intentionally not respond for security measures.

### <a name="netdiscover"><span style="color: var(--title)">02.00 NETDISCOVER</span></a>

<hr>

`netdiscover` is an ARP reconnaissance tool which asks <span style="color: var(--highlight)">who is currently on my local network ?</span> It basically listens to the devices on the network when they ask 'hey, who is XX ip address ?' and the owner of the ip address answers 'hey ! I am XX, this is my MAC address'

to probe only 'my' network : `sudo netdiscover -r 192.168.3.0/24`

### <a name="nikto"><span style="color: var(--title)">03.00 NIKTO</span></a>

<hr>

`nikto` is a command which basically answers <span style="color: var(--highlight)">what is wrong with X website</span>. Nikto will basically send hundreds to thousands of HTTP requests to check for known misconfigurations, exposed files or directories, outdated software, known security issues, etc.

nikto -h scanme.nmap.org
